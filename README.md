# ☕ Java Practice Projects

Java backend engineering implementations covering OOP, Collections, JDBC, SQL, transaction management, and backend fundamentals through real-world applications.
The goal of this repository is to strengthen Java fundamentals by building console-based applications and implementing real-world programming concepts.

---

## 📂 Projects

### 🚗 Car Rental System
A console-based car rental application demonstrating the core principles of Object-Oriented Programming.

**Concepts Used**
- Object-Oriented Programming (OOP)
- Encapsulation
- Inheritance
- Polymorphism
- Collections Framework
- Exception Handling

---

### 🚆 Train Booking System
A console-based train ticket booking application using JDBC and MySQL.

**Concepts Used**
- Core Java
- JDBC
- MySQL
- DAO Pattern
- CRUD Operations
- Layered Architecture
- Exception Handling

---

### 💳 JDBC Transaction System
A Java application demonstrating transaction management using JDBC.

**Concepts Used**
- JDBC
- Commit & Rollback
- Savepoints
- Transaction Management
- Exception Handling
- MySQL
